# Curated evidence

`vivo-reference.json` summarizes selected archived source reports. It keeps their
hashes and named operations, without copying the private reports or runtime state.
The mathematical app has physical user verification; Hub automated touch events
and real Android HTTP contact are explicitly separate.

`m1-validation.json` records the portable repository checks actually executed on
the reference development interpreter. Windows/PowerShell, Android builds and
clean-device tests remain pending until their own evidence exists. The private
local baseline and detailed command outputs are ignored under `.local/`.

The repository's own final commit cannot contain its own hash. Remote publication
is verified separately and reported with the confirmed branch/commit identifier.
CI configuration alone is not evidence that GitHub Actions has executed.
